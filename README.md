# Cyber Security Fundamentals & Interactive Perimeter Hub

An interactive, responsive cyber security landing page built as a demonstration of modern front-end engineering combined with core defensive architecture principles. 

## 🚀 Live Demo
Experience the interactive live site here: [Click to View Live Site](NgixFraud.html)

## 🛡️ Core Features
* **Interactive Dynamic Search Bar:** Built with a pure JavaScript automated typing effect highlighting critical cyber threat vectors.
* **Premium Cybersec UI:** A high-end, responsive dark-mode layout designed with an industry-standard terminal aesthetic.
* **CIA Triad Framework Integration:** Structured knowledge base detailing Confidentiality, Integrity, and Availability concepts.
* **Tactical Consultation Interface:** A clean, validation-ready intake form for perimeter and log audits.

## 💻 Tech Stack
* **Structure:** HTML5 (Semantic Elements)
* **Styling:** CSS3 (Custom Typography & Glow Effects)
* **Interactivity:** Vanilla JavaScript (Asynchronous Typing Engine)
* **Iconography:** Font Awesome v6.4.0
